# FileCompare

文件查重小工具：找出文件夹里的重复文件，帮你安全清理。

## 功能

- **完全重复**：按字节比对，零误判
- **相似照片**：感知哈希 + 颜色直方图比对
- **格式副本**：同一张照片的 RAW+JPEG / HEIC+JPG（按同名不同格式或 EXIF
  同机型同一秒识别，默认保留 RAW、不勾选）
- **重复视频**：抽帧签名比对
- **重复音乐**：标签 + 声学指纹（需 fpcalc）复核
- **同名相似**：文件名相同、内容未校验的归一组，默认不删
- **重复目录**：目录内直接文件的文件名 + 大小完全一致，内容未校验，默认不勾选，不能直接清理
- **重复压缩包**：zip 家族（zip/jar/apk/whl/epub…）内条目名 + CRC + 大小
  完全一致，默认不勾选
- **截图标记**：文件名像截图的相似照片组会在说明里标「（截图）」
- **文件整理**：按类型或日期归档，移动前确认、可撤销
- **批量重命名**：替换、前后缀、模板、大小写，两阶段执行、可撤销
- **照片去水印**：框出水印位置（可多框），用四周画面反射补上；可选 LaMa 模型做语义级修复；文档/表格截图可一键抠浅色半透明水印（淡黄/淡蓝/淡粉/淡绿/淡灰自适应，反解叠加而不补图，跑完自动弹前后对照），均另存新文件、原图不动
  （不联网、不依赖外部模型）

## 安全

- 删除默认移入回收站，永久删除要二次确认
- 移动、整理、改名都会写操作记录（`_操作记录` 目录），可用
  `python dedup_tools.py undo --kind organize|rename|finder` 撤销；
  移入回收站的清理用图形界面的“还原上次清理”恢复
- 清理时保留项和受保护目录里的文件不会被删

## 运行

需要 Python 3.10 以上，装好 numpy、Pillow。

图形界面：

```
python dedup_gui.py
```

或双击 `run_gui.bat`。

命令行：

```
python dedup_finder.py <要扫描的目录>
```

`run.bat` 只查重（原文件不动）；`run_organize.bat` 查重 + 按类型归档；
`run_move.bat` 查重 + 重复文件直接移入结果目录。移动前会询问确认，
加 `--yes` 跳过询问。

可选依赖：fpcalc（音频声学指纹）、ffmpeg / ffprobe（视频签名）。
