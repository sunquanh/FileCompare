# FileCompare

文件查重小工具：找出文件夹里的重复文件，帮你安全清理。

## 功能

- **完全重复**：按字节比对，零误判
- **相似照片**：多级流水线（感知哈希 → 直方图/布局 → 结构相关 → 缩放/旋转/平移
  对齐 → EXIF 救援），可选深度特征层提召回
- **格式副本**：同一张照片的 RAW+JPEG / HEIC+JPG（按同名不同格式或 EXIF
  同机型同一秒识别，默认保留 RAW、不勾选）
- **重复视频**：抽帧签名比对
- **重复音乐**：标签 + 声学指纹（需 fpcalc）复核
- **同名相似**：文件名相同、内容未校验的归一组，默认不删
- **重复目录**：目录内直接文件的文件名 + 大小完全一致，内容未校验，默认不勾选，不能直接清理
- **重复压缩包**：zip 家族（zip/jar/apk/whl/epub…）内条目名 + CRC + 大小
  完全一致，默认不勾选
- **截图标记**：文件名像截图的相似照片组会在说明里标「（截图）」
- **文件整理**：按类型或日期归档，移动前确认、可撤销
- **批量重命名**：替换、前后缀、模板、大小写，两阶段执行、可撤销
- **照片去水印**：可以整文件夹，也可以直接选一两张照片（多选、跨文件夹）；
  框出水印位置（可多框，位置会被记住），三档修复任选，模型就绪时默认走
  质量最高的 LaMa；“一键抠”会把记住的框一并套用，白字徽标（AI生成这类）
  框一次以后就不用再框；照片不再做文档式反解（会把皮肤/天空当水印抹掉）；文档/表格截图可一键抠浅色半透明水印（淡黄/淡蓝/淡粉/淡绿/淡灰自适应，反解叠加而不补图，跑完自动弹前后对照），均另存新文件、原图不动
  （不联网；只有高质量档需要本地模型）

## 照片去水印：三档怎么选

| 档位 | 界面开关 | 依赖 | 适合 |
| --- | --- | --- | --- |
| 自动（默认） | 都不开 | numpy | 角落 logo、时间戳、横/竖水印条，毫秒级 |
| 纹理合成（中档） | 开「纹理合成」 | numpy | 草地、布料、砖墙等重复纹理，约 0.5~1 秒/处 |
| 高质量（LaMa） | 开「高质量」 | onnxruntime + `models/lama_fp32.onnx` | 水印压在人物、结构上，约 7 秒/处 |

自动档按框形状分派：横条走竖列复制、竖条走横行复制、近方形走四方向中位数反射；
四方向反射带四边接缝亮度校正（对天空、逆光渐变有效），未覆盖到的像素由局部
金字塔扩散兜底——扩散只在「框 + 16 像素边距」内求解，4000×3000 大图上补一个
小角落也不会按全图尺寸迭代。

中档是纯 numpy 的简化 PatchMatch：从框由外向内逐环找最相似的 patch，结构化平移
+ propagation + random search，重叠处加权平均；不需要模型文件。高质量档里
≤512 的窗口直接贴进 512 画布（反射补边、掩膜同步平移），推理完按原像素取回，
不做「放大→推理→缩回」；超过 512 的大框改走带重叠的滑窗平均，同样不整体缩小。

浅色水印一键清理会先从掩膜里自估水印参考色，再用「反解后残余偏色最小」在固定
色表、自估值、两者折中之间闭环择优，各 App 的非标准水印色不容易估偏 α。

所有档位都保证**框外像素一个都不动**。只处理自己有版权的照片。

## 照片去重：判定链路

从便宜到贵逐级放行，任一级过门即合并；后一级只在前面都没过时才跑。
任何一级的结论都要先过一道**拍摄信息否决**：两台相机不同、或同一台相机但
拍摄时间差 >2 秒，就是先后两次快门，画面再像也不算同一张的副本——副本
（另存/压缩/裁切/换目录）会原样保留 DateTimeOriginal，所以这条不会误伤。
没有 EXIF 的图（截图、被剥掉信息的副本）不作判断，行为不变。

1. **同尺度**：dHash 粗差 + pHash 细差 + 结构相关 + 颜色布局
2. **分块救援**：把 32×32 高频切成 4×4 块各算相关，丢掉最差的 3 块再平均。
   贴纸、大字、局部马赛克只污染个别块，整幅点积却会被拉到门限以下。
   叠加稳健布局（8×8 布局丢最差 1/4 块）与连拍否决。
3. **EXIF 救援**：同机型 + 拍摄时间 ≤2 秒。这条路误报风险最高（连拍相邻帧
   人动一下也满足），所以读 SubSecTime（37520/37521/37522）区分连拍帧，
   并要求「体积或像素面积明显更小」这类派生副本特征才放行。
4. **缩放/旋转搜索**：中心梯子 → 内缩窗口（去白边）→ 偏心矩形窗口 →
   小角度旋转（±3/5/10°）。候选队列按「径向缩放不变签名 + 深度余弦」排序，
   不再靠直方图距离猜，`ZOOM_MAX_PAIRS` 截断不会静默漏掉真候选。
5. **任意角度对齐**：Fourier–Mellin 对 64×64 幅度谱做 log-polar 相位相关，
   一次解出旋转角与缩放比，覆盖 7°/15° 这类离散梯子够不着的角度；平移用
   普通相位相关直接估。只产出候选，是否合并仍由对齐后的 NCC + 布局双门决定。
6. **可选深度特征**：`models/photo_embed.onnx`（705 KiB）给出 128 维向量，
   余弦相似度作为独立判据——高余弦时与手工门联合提召回，低余弦时否决
   EXIF/分块救援压误报。**没装 onnxruntime 或没有模型文件就整层跳过**，
   行为与旧版完全一致，不联网、不下载。

缩略图缓存是 96×96（早期是 64×64），深裁切后仍有足够像素做 NCC。
模型由 `tools/train_photo_embed.py` 离线训练导出，主程序不 import 它。

## 安全

- 删除默认移入回收站，永久删除要二次确认
- 移动、整理、改名都会写操作记录（`_操作记录` 目录），可用
  `python dedup_tools.py undo --kind organize|rename|finder` 撤销；
  移入回收站的清理用图形界面的“还原上次清理”恢复
- 清理时保留项和受保护目录里的文件不会被删

## 运行

需要 Python 3.10 以上，装好 numpy、Pillow。

图形界面：

```
python dedup_gui.py
```

或双击 `run_gui.bat`。

命令行：

```
python dedup_finder.py <要扫描的目录>
```

`run.bat` 只查重（原文件不动）；`run_organize.bat` 查重 + 按类型归档；
`run_move.bat` 查重 + 重复文件直接移入结果目录。移动前会询问确认，
加 `--yes` 跳过询问。

可选依赖：fpcalc（音频声学指纹）、ffmpeg / ffprobe（视频签名）。
